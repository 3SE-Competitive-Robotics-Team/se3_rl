# Rough 姿态罚加倍（Orient24，2026-10-04）

## 改动

`tracking_orientation_l2`（pitch/roll L2，rough 的 pitch/roll 指令恒 0）权重 −12 → −24，其余不变。
依据：JumpCol10 基线平均倾角约 10°、11% 时间超过 15°，姿态罚每秒只有速度跟踪奖励的约 8.5%；
`bad_tilt` 已在 M37 删除，倾角终止已在 M47 删除，15°–30° 只剩这一项二次罚。

| 地形网格（10 种 × r3/6/9）通过率 | 93%（wave 33%，两级下台阶 83% 且摔 1） | 100%，0 摔 |
| 地形网格 平均 / p95 / 最大倾角 | 8.7° / 20.8° / 23.2° | 4.4° / 11.8° / 15.0° |
| 地形网格 vx 误差 | 0.50 | 0.29 |
| 平地 vx 误差、俯仰抖动 | 0.213、1.36° | 0.082、0.47° |
| 转向 1/2/4 rad/s 误差 | 0.07 / 0.13 / 0.15 | 0.03 / 0.03 / 0.09 |

逐地形平均倾角：平地 9.3° → 3.6°，坡 8.1–10.0° → 3.4–4.8°，起伏 / 障碍 / 波浪 8.9–11.1° → 4.5–5.2°，台阶 6.1–11.6° → 2.8–6.6°。

结论：−24 在姿态、跟踪、通过率上全面占优，代价是起步慢约 0.2 s。2026-10-04 用户定为新默认（`env_cfg.ROUGH_ORIENTATION_WEIGHT`）。

## 两条 run 共有、与本项无关的问题（待单独对照）

1. **跳跃落地**：两条 actor 128 run 落地后机身蹲到约 0.19 m（参考 0.22 m），参考播完、jump_flag 1 → 0 时猛地站起、俯仰掉到约 −20°；
   落地后 |俯仰| 最大 18–24°、下沉 23–47 mm，1 s 内多数不稳定。50 Hz 老基线（actor 512、旧 RSI bug）落地后 7.5–13°、下沉 4–12 mm。
   嫌疑：actor 变小后跳跃学得不够（待 −24 + actor 512 对照）。
2. **中等高度跑动站高**：高度指令 0.26–0.34 m 时，0.5–1.5 m/s 稳态机身比指令高 4–6 cm（静止时准）。
   反事实账本（训练环境平地列、计酬指令固定、观测里的高度指令调低让实际贴合）：贴合时总奖励反而高 1.0/s（1.0 m/s、0.30 m）
   与 4.8/s（0.5 m/s、0.26 m），说明不是奖励权衡而是没学好。嫌疑：`high_stand_transition_prob = 0.5`
   使任意时刻约 26% env 处在"0.36–0.38 m 高姿态静站 → 前进"序列中（待降到 0.1 的对照）。
3. **平地固定前后倾**：质心始终正对轮轴，默认站姿本身水平平衡；倾斜来自两腿共同偏离高度默认站姿
   （平衡求解复现实测，左右对称化不改变俯仰），小角度 L2 罚梯度太小。−24 未消除（0.30 m 静站仍 +7.5°）。
