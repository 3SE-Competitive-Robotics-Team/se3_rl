## 背景

M28（`ayrbsbfy`，复旦 v3 全地形统一奖励）平地、坡道、下台阶都正常，上台阶列等级停在 1.4–1.7（台阶约 5 cm），
热身结束后还在往下掉（900 轮 1.68 → 1481 轮 1.44）；同期 M25–M27 在 1200 轮已到 4.3–5.9。sim2x 里 model_1400
在 vx 2.4 时能冲上复旦场景的 20 cm 台阶，低速上不去——学到的是靠动量撞上去（整体抬升 20 cm 需 ≥1.98 m/s）。

复旦仓库 `plane/logs/wheel_legged/` 的 7 份快照（上台阶1 → 2 → 3 → 3_angz+ → 进一步训练 v1 → v2 → v3）显示，
各段奖励函数完全相同、没有任何台阶专项项；学会上台阶的那几段（上台阶2 到 3_angz+）姿态罚是 **−10**，
−20 是 v1 才加的（同时加了混合地形与指令课程），M28 照搬的是 v3。

## 改动（相对 M28，两项由用户一并指定）

任务入口 `SE3-WheelLegged-Rough-Exp-FudanRewardOri10`（`env_cfg(reward_set="fudan_v3",
fudan_scale_overrides={"orientation": -10.0})`）。

1. **orientation −20 → −10**，其余 14 项权重不变。
2. **高度参考改成复旦 `_get_heights` 的格点口径**（`fudan_rewards.fudan_ground_height`）：机身周围 11×7 个点只随
   偏航（twist 角）转，落到 0.1 m 世界格点取整，每点取本格与 +x、+y 两个相邻格点里最低的高度，77 点全部求均值。
   我们的地形不在格点上建，开训时把整张地形在 0.1 m 格点上的表面高度离线算一遍（box 栅格化、hfield 用 mj_ray），
   约 5 s。M28 用的是 critic 77 条射线打到的真实表面、丢掉打空或打背面的射线。

   两种口径的实测差（随机 3000 个机身位姿，复旦口径 − 真实表面）：box 地形均值 −0.02 cm（不在格线上的二级台阶
   立面附近最多 −3.3 cm），hfield 斜坡均值 −0.55 cm、p5 −1.7 cm、最多 −2.75 cm（格点取最低 = 平均低半格坡升）。
   格点表与 mj_ray 抽检 4000 点最大误差 0.1 mm；reset 时平台上 77 点均值与地块原点高度差 ≤ 5 mm。

   M28 入口在本提交之后也改用格点口径；M28 的 run 本身用 commit `6f25ca9` 复现。

不变：指令（高度 0.20–0.38 + 台阶列随等级抬高的下限、每 5 s 重抽）、课程、终止、观测、域随机化、PPO。
高度口径的差只有厘米级、主要在斜坡上，上台阶的结果差异主要归到姿态罚；如需拆开再单独跑。
