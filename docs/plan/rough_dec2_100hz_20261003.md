# Rough 推理 100 Hz 对照（Dec2 / Dec2-Steps48，2026-10-03）

## 问题

推理频率从 50 Hz 提到 100 Hz 能否改善 rough 策略。参考：Unitree 官方 Go2（unitree_rl_gym / unitree_rl_lab /
unitree_rl_mjlab）都是 50 Hz（5 ms × decimation 4）、γ 0.99 / λ 0.95 / 每轮 24 步；复旦 wheel_legged_gym 轮腿是
100 Hz（5 ms × decimation 2）、γ 0.99 / λ 0.95 不换算、**每轮 48 步**、desired_kl 0.005、actor 128/64/32。

## 对照（单变量，seed 42，6 卡 × 2048，基线 JumpCol10 `06j74ep2`）

| run | 改动 | commit | W&B |
|---|---|---|---|
| 基线 | 50 Hz，每轮 24 步 | `6303547` | `06j74ep2`（whtws，3005 轮停） |
| Dec2 | decimation 4 → 2，其余不变（每轮只覆盖 0.24 s） | `69fd369` | `nifnih7d`（nulltask1，2730 轮停） |
| Dec2-Steps48 | Dec2 + 每轮 48 步（每轮仍覆盖 0.48 s，同复旦） | `07fe1c2` | `ibxio1cm`（nulltask1） |

三条都带 `c0c791f` 修掉的旧 RSI 残留 bug（见 rough_iteration_time_20261003.md），彼此可比。

## 结果（第 2600 轮 ONNX，sim2x 同链路确定性回放）

| 指标 | 50 Hz 基线 | Dec2 | Dec2-Steps48 |
|---|---|---|---|
| 平地 vx 误差（21 组均值） | 0.128 | 0.109 | 0.117 |
| 机身俯仰抖动 | 0.41° | 1.22° | 0.26° |
| 腿部动作变化量（50 Hz 口径） | 0.0056 | 0.0107 | 0.0056 |
| 转向 1/2/4 rad/s 误差 | 0.08/0.15/0.07 | 0.08/0.17/0.30 | 0.01/0.00/0.07 |
| 零转向直行偏航（纯平地 / 台阶后） | 1.1 / 2.4 °/s | 4.9 / 5.7 °/s | 1.5 / 1.7 °/s |
| 跳跃离地 / 目标、最大倾角 | 1.03、11.1° | 1.05、11.2° | 0.96、13.4° |
| 台阶 1–9 级爬出 4 m 用时 / 卡顿 | 4.53 s / 0.43 s | 5.08 s / 0.84 s | 4.88 s / 0.82 s |
| 单轮墙钟（6 卡 × 2048） | 2.3 s | 1.8 s | 3.5 s |

W&B 同轮次曲线上 Dec2-Steps48 与基线几乎重合（奖励、vx 误差、地形等级、跳跃比例都在 ±2% 以内）。

## 结论

1. Dec2 的转向偏快、直线漂移、动作发碎来自**每轮只覆盖 0.24 s**，不是频率本身；补到 48 步后全部消失。
2. 100 Hz（配 48 步）对 50 Hz 有输有赢：转向与机身平稳略好，跳跃略矮略晃、台阶爬得慢，没有一边倒的收益；
   同轮次墙钟慢约 50%。
3. 2026-10-04 用户定：维持 50 Hz，删除 Exp-Dec2 / Exp-Dec2-Steps48 入口与 env_cfg 的 decimation / steps_per_policy_iter 开关。
   单 seed、半程结论；需要复现时切回上表 commit。
