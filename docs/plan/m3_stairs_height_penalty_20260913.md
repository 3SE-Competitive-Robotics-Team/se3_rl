# M3：台阶列加回机身高度罚（2026-09-13）

对照基线：M2（W&B pvkgmbh0，commit 4084e19）。M2 终评见 `m2_stairs_pricing_20260913.md` 末三节。
用户 2026-09-13 定：只改这一项，四卡起训。

## 假设

M2-4999 的确定性回放在平地中速指令（0.8–2.0 m/s）掉进 0.8 Hz 弹跳极限环（机身 z 极差 20 cm、vx 1.3–3.5 脉动），
从 1200 轮起就不跟中速指令、3000 轮起弹跳；台阶通关 72/72 却是 1200 就到顶。台阶列上机身高度自 A 系列起不受约束
（高度罚置零，只有指令下限），怀疑弹跳步态是在台阶列养出来、泄漏到平地的。加回高度罚看平地是否恢复、台阶是否退步。

## 改动（相对 M2 单变量）

| 项 | M2 | M3 |
|---|---|---|
| `flat_base_height`（权重 −4，σ 0.10，误差夹 ±0.15 m） | 台阶列置零 | 全列生效（`ROUGH_BASE_HEIGHT_OFF_COLUMNS = ()`） |
| 其余（三项台阶列置零、摔倒罚、台阶专项奖励、课程、地形） | 同 | 同 |

台阶列上的量级：误差贴夹紧值时 (0.15/0.10)² × 4 = 9/s，跨立面时传感器高度会瞬间少一个阶高（最高 0.20 m），
这项会在每次跨立面时短暂贴封顶；台阶列指令下限（阶高 + 0.02 + 0.12）不变。
