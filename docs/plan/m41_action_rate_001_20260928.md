# M41：删 action_smoothness、action_rate −0.01（2026-09-28，用户定）

## 背景

M39（action_rate −0.48 → −0.10）与 M40（再把 action_smoothness −0.12 → −0.06）显示：动作罚每减一档，动作幅值就补回一部分，
实付降得比权重慢得多（M40 台阶列 action_smoothness 仍是最大负项 −0.65/s，两项动作罚合计 −1.01/s），而动作质量、静站抖动没有变坏，
说明这两项权重历史上是在管 σ 而不是在管动作（Flat D 系列把动作罚当探索噪声调节器标定，−0.48 是 legged_gym 常规值 −0.01 的 48 倍；
action_smoothness 是本仓库多出来的一项）。用户决定：`action_smoothness` 整项删除，`action_rate` 改为常规值 −0.01。

## 风险

按 k = 2·w_rate + 6·w_smooth 标定，M41 的 k = 0.02（M40 0.56），σ 的外推已不可信（形式上约 0.9）。噪声约束只剩 leg_torques /
leg_dof_acc / 跟踪核本身与 PPO entropy。轮动作噪声 σ×45 rad/s 在确定性回放里看不到，实机会是可见抖动。
提前停止判据：`Policy/mean_std` 超过 0.6 持续 200 轮，或 `model_*` 静站腿峰峰超过 10°。

## 改动（相对 M38 默认：两处；相对 M40：删 smoothness + action_rate −0.10 → −0.01）

任务入口 `SE3-WheelLegged-Rough-Exp-ActionRate001NoSmooth`：`env_cfg(action_rate_weight=-0.01, action_smoothness_weight=0.0)`，
`action_smoothness_weight=0.0` 表示整项删除。配置核验：相对默认少 `action_smoothness` 一项、`action_rate` −0.48 → −0.01，其余 23 项逐位相同。
本条不是单变量对照，是用户对动作罚整组的重新定价。
