# M30：M29 + actor 初始 std 1.5（2026-09-26，用户定）

## 背景

M28（姿态罚 −20）与 M29（−10 + 复旦格点高度参考）的上台阶列等级都停在 1.2–1.7（台阶约 5 cm）并在热身后下降，
只会在 vx ≥ 2 时靠动量冲上 20 cm。复旦 PPO 的 `init_noise_std = 1.0`、腿动作缩放 0.5 rad，初始腿目标角噪声 0.5 rad；
我们 `init_std = 0.5`、腿 0.25 rad，只有 0.125 rad。复旦各段是否续训（std 会随 checkpoint 继承）仓库里核实不了，
这里直接检验"大探索噪声能不能让统一奖励表学会动腿上台阶"。

## 改动（相对 M29 唯一差异）

任务入口 `SE3-WheelLegged-Rough-Exp-FudanRewardOri10Std15`：env 与 M29 完全相同，`rough.rl_cfg(init_std=1.5)`
只把 actor 高斯分布的初始 std 从 0.5 改成 1.5（`std_type="scalar"`，每个动作维一个可学习 std，照常由 PPO 与
entropy_coef 0.01 调整）。

初始噪声换算：腿目标角 1.5 × 0.25 = 0.375 rad（复旦 0.5 rad、M29 0.125 rad）；轮速目标 1.5 × 45 = 67.5 rad/s
（复旦 10 rad/s、M29 22.5 rad/s），轮子上的噪声比复旦大得多，主要看 PPO 能否先把轮子维的 std 收下来。

## run 设置

nulltask1 六卡 × 8192 envs、8000 轮、保存间隔 200、seed 42，W&B project `SE3-WheelLegged-Rough`，与 M28/M29 同配置。

## 判据

- 上台阶：stairs_up 与 M29 同轮次比（M29：700 → 1.67、1200 → 1.45、1800 → 1.20），1500 轮前超过 2.5 才算在学爬；
  二级台阶门控（均级 ≥ 5）能否打开。
- 早期稳定性：`Policy/mean_std` 的轨迹（初值 1.5）、`Train/mean_episode_length` 与倾覆/灾难终止在前 500 轮是否失控；
  速度课程能否照常推满 2.4。
- 平地跟踪 `Rough/tracking_lin_vel_flat` 不低于 M29 同期（0.72–0.77）。
