## 附：左右轮前后错位（"两轮间距"）评测（2026-09-21，`.scratch/m17_eval/gap/wheel_gap.py`）

量的是机身系里左轮减右轮的前后错位 Δx（+ 为左轮在前）、高低差 Δz、轮心直线距离（名义 0.433 m）。确定性回放、后 10 s 均值：

| 工况 | M15 Δx (cm) | M17 Δx (cm) | M17 轮心距 (m) |
|---|---:|---:|---:|
| 22 cm 前进 0.8 / 1.2 / 2.4 | −2.6 / −2.5 / −1.6 | +22.0 / +23.4 / +22.5 | 0.486–0.493 |
| 30 cm 静站 / 0.4 / 0.8 / 1.2 / 2.4 | −7.3 / −6.1 / −10.9 / −2.9 / −1.5 | +9.4 / +17.6 / +23.8 / +28.0 / +28.7 | 0.443–0.520 |
| 38 cm 静站 / 0.8 / 1.6 | +16.1 / −20.0 / −19.4 | −25.7 / +17.4 / +22.8 | 0.467–0.504 |
| 倒退 30 cm −0.8 / −1.6 | −3.5 / −0.7 | −5.8 / −7.4 | 0.437–0.440 |
| 20 cm 台阶（0.34, 1.0）| 均 −6.6，±4 | 均 +3.4，±10（最大 20）| 0.456 均、0.50 峰 |

Δz 都在 2 cm 内，轮子都着地——不是抬轮，是**跨立步态**：前进时一条腿前伸一条后收，左右轮前后错开 20–29 cm，轮心距拉到 0.49–0.52 m。
M15 在 22/30 cm 只有 2–11 cm，38 cm 也有 16–20 cm；M17 在所有高度、所有前进速度都是 20–29 cm，方向随行进方向翻转（前进左轮在前、倒退右轮在前）。
机理：两轮前后错开后机身俯仰不再是倒立摆，速度跟踪几乎变成静定问题；窄核 w=3 把精确跟踪的价值抬高，这个步态也就更值钱。
现有 `joint_mirror`（权重 −0.179，关节空间镜像误差）在 Δx=28 cm 时只花 0.18/s，对比跟踪项 6–9/s 形同免费；训练端 Episode_Reward/joint_mirror 仅 −0.02。
台阶上 Δx 随立面周期性摆动 ±10–20 cm，是爬升动作的一部分，罚项若全列同权重可能伤台阶。

罚项设计建议（未实施）：直接罚几何量 Δx（轮心在机身系的前后差，`robot.data.body_pos_w` 即可算，不需要传感器），二次型 w·Δx²，
w 取 30–50/m² 使 25 cm 花 2–3/s（与跟踪激励同量级）、5 cm 只花 0.1/s；平地式列生效，台阶列用 `off_column` 置零或减半；直立门控沿用。
不建议只调 `joint_mirror` 权重：它混了髋膝、四连杆映射非线性，同一 Δx 在不同高度对应的关节差不同。
