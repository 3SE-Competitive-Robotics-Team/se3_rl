# sim2x 缺的被控对象结构：轮通道候选扫描（Student128-6998，2026-10-14）

问题：实车（STM32 片上 Student128-6998，策略 50 Hz、PD 1 kHz）2026-10-14 增益扫描 A–E 给出可对照的工作点，
sim2x 在 A–D 都不振荡。本轮回答"仿真缺的是什么"：逐个把候选结构加进诊断用被控对象，看能否**同时**复现五组工作点。
不是把抖动调没，也不做以消抖为目的的参数拟合。不改 `src/`、`submodules/`、正式 assets，不连硬件。

## 结论

**没有候选同时满足五条判据**（117 个候选 × 5 组 × 静站 / 注入两种工况，共 1170 次仿真）。A 在任何候选下都不在 7.8–8.6 Hz 自激。

- **能确认缺的一项：轮通道（转子编码器到接地点之间）的扭转柔性，k ≈ 30–60 N·m/rad**（2 N·m 时扭转约 2–4°；
  闭环效果等价于 5–10 ms 的轮力矩有效滞后）。证据有两条、彼此独立：
  1. 只用实车同步数据（不经仿真闭环）：编码器角扣掉 (τ_m + J_r ω² θ_r)/k 后，刚体整机俯仰平衡要求的俯仰角速度由
     刚性的 0.70×、+31° 变为 0.95–1.04×、+14–24°，左右轮纯滚动预测的髋轴加速度不一致由 65% 降到 29–41%（`summary_tables.md` 表 4）。
  2. 闭环仿真：k 30–50 时 D 在 6.5–7.1 Hz 失稳（k 60 临界），E 在 6.3–7.0 Hz 失稳，C 的 6 Hz 模态阻尼比由基线 0.06
     降到约 0.01–0.03，B 静默，E 使能沿最强；
     D 的运行变形形态（各通道相对俯仰角速度的复比值）与实车 D 同量级，用等效的 10 ms 轮力矩滞后表示时最吻合
     （腿角 0.8–1.1 倍、轮速 1.03–1.12 倍、相位差 ≤ 23°）。
- **它不充分**：A 的 7–9.5 Hz 模态阻尼比始终停在 0.03–0.07；继续加大轮通道相位滞后，只会让 D/E 振得更大、频率更低
  （5.3 Hz），或者先让 A/B 在 3–4 Hz 失稳（实车没有）。D 的主频比实车低 0.2–1.5 Hz、俯仰幅值只有实车的 1/6–1/2。
- 因此还缺**一项让 Kp 60 / Kd 3 工况在约 8 Hz 失去阻尼、并整体抬高模态频率**的结构，它不在 (a)–(e) 里：
  腿链柔性、机身惯量 / 质心、轮转子惯量、接触软硬、以及清单外加测的腿执行器滞后上限都已否定（见下表）。

## 方法

- 配方 = `scripts/predict_gain_sweep_20261013.py`（主模型 4e1aeb0；固件陀螺 Q/R、腿速度 4.7 ms、腿 12 ms / 轮 3、4 ms
  按时间门控一阶滞后、气弹簧 400/360 N 第 6 s 淡入、实测静置噪声、失能趴姿落地 3 s 再使能静站 18 s）。增益按 A–E
  只在诊断 adapter 层覆盖。基线 A 的轨迹与预测脚本**逐位相同**（float32 差 0.0）；Pod 与本机同一工况指标相差 < 1e-4。
- 候选只进 `.scratch/wheel_channel_fit_20261014/mjcf/` 的 MJCF 副本或 adapter：(a) 轮 geom solref（以接触固有频率
  4–34 Hz、阻尼比 0.1–1.25 参数化）；轮体内加与轮轴同轴的"胎面"自由度，扭转刚度 10–320 N·m/rad、阻尼比 0.05–0.4、
  惯量外侧比例 0.5/0.9，另加单侧间隙 0.25–1°；(b) 轮力矩一阶滞后 5–20 ms、纯延迟 2–10 ms、轮速测量滞后 2.5 ms；
  (c) 轮 armature 0.0035/0.0075；(d) 四个腿电机关节移到电机侧 body，经 15–500 N·m/rad 链扭转弹簧带动原连杆，
  PD 与观测接电机侧；(e) 机身俯仰惯量 ×0.5–×2（按二阶矩沿 x、z 拉伸保持可实现）、质心 ±4 cm。组合：胎面 25–60 ×
  7 种第二因素。清单外：腿力矩滞后 15/18 ms、8 ms 纯延迟 + 5 ms（实测电流反馈 31–38° 的上端）。
- 判据与谱口径同 `scripts/analyze_gain_sweep_20261014.py`：谐波回归主频（3–14 Hz）、Welch fs 1000 / nperseg 900 /
  noverlap 450 的 5–15 Hz RMS、同频指令层功率 0.5·Re(F·conj(v))；稳态取 8–17.94 s 的 10 个 0.94 s 窗（与实车每段
  940 点同长），使能沿同样 0.2 s 窗 / 0.1 s 步。另做 8.3 Hz 观测注入（0.4 rad/s，8–12 s），用撤除后的振铃频率与
  阻尼比衡量"离失稳多远"。判据：A 持续自持（r² 中位数 ≥ 0.8、俯仰 RMS 中位数 ≥ 0.1 rad/s 且无掉窗、7.8–8.6 Hz）；
  D 以 A 自持为前提，幅值大于 A、f_D/f_A 0.85–0.95；B、C 幅值 < A 一半且可检出振荡在 5.8–7.0 Hz；E 使能后
  0.5–0.9 s 俯仰带通 RMS 大于 A。
- 批量仿真在 nulltask1 Pod 上跑（CPU 48 进程、BLAS 单线程，运行前实时查过负载与 GPU，未碰别人的任务）。

## 五类候选结论（逐组数值见 `summary_tables.md` 表 2，与实车逐项对照见表 3）

| 类别 | 候选数 | 结论 |
|---|---|---|
| (a) 接触 solref | 11 | **否定**。4–34 Hz、ζ 0.1–1.25 对 6–9 Hz 闭环模态几乎无作用：A 俯仰 RMS ≤ 0.011 rad/s，D 不失稳 |
| (a) 胎面 / 转子–轮体扭转柔性 | 28 | **必要但不充分**。k 30–50：D 6.5–7.1 Hz、E 6.3–6.8 Hz 失稳，C 6 Hz ζ 0.01–0.03，B 静默；A 振铃 8–9.5 Hz ζ 0.04–0.07 不自激；k 60 时 D 临界。k ≤ 20 或间隙 ≥ 1° 时 A/B/C 出现 3.5–4.6 Hz 极限环（实车没有） |
| (b) 轮力矩滞后 / 延迟 | 10 | **纯电气滞后否定，作为 (a) 的等效描述保留**。10 ms 滞后或 5 ms 延迟与胎面柔性同效（7.5 ms / 3 ms 时 D 临界），D 形态最吻合；但实车电流反馈只落后 8–11°（≈3 ms，基线已含）；≥ 15 ms / ≥ 10 ms 时 A/B 在 3–4 Hz 失稳。实测轮速测量滞后 2.5 ms 只轻微加重 D |
| (c) 轮转子惯量 | 2 | **否定**。只小幅移动频率；与胎面组合时 0.0075 让 A/B 出现 3 Hz 左右低频振荡 |
| (d) 腿链柔性 | 8 | **否定**。15–30 使能后 0.4 s 摔倒、60 时 A/B/E 在 1.4–11 s 内摔倒；120–500 时策略落到另一种站姿（站高 0.25–0.30 m，电机侧腿角偏离实车 8–10°）、A/B 3–5 Hz 不规则运动、E 摔倒；实车数据扣链扭转后平衡相位误差反而变大（+31° → +33–40°）。≥ 1000 时驱动杆惯量太小、1 ms 步长发散，未评价 |
| (e) 机身俯仰惯量 / 质心 | 8 | **否定**。惯量反比移动频率（×0.5：A 振铃 9 Hz、D 8 Hz）但 A 不自激，×0.5 还让 B 在 3.9 Hz 剧烈振荡；质心 ±4 cm 不让 A–D 振荡（+4 cm 反而让 E 静下来） |
| 组合（胎面 × 第二因素） | 40 | **否定**。相位滞后越大 D/E 越大、频率越低（5.3–7.3 Hz），A 仍是 7–9.5 Hz、ζ 0.03–0.08 的阻尼模态或先在 3–4 Hz 失稳 |
| 清单外：腿执行器滞后上限 | 9 | **否定**。不让 A 失稳；与胎面组合反而让 D 稳定；8 ms 纯延迟 + 胎面让 A/B 3 Hz 大幅失稳 |

## 下一步需要的实车测量

1. **轮通道静态扭转标定**（判定 (a) 是否成立、给出 k 与间隙）：机身架空、轮胎压住地面或夹住胎面，轮电机给 ±0.5 / 1 / 2 N·m
   慢变力矩，读编码器角；若 k 为 30–60 N·m/rad，2 N·m 时转角应为 2–4°。
2. **轮通道动态**：同一夹持下 2–20 Hz 小幅力矩扫频，转子编码器加胎面外部测量（第二编码器 / 高速相机 / 轮上 IMU）。
3. **腿传动与执行器**：机身固定、轮离地，单腿 1–20 Hz 小幅力矩扫频，电机编码器加大腿外部角度，得到链 / 减速器柔性和
   各腿真实力矩滞后与增益（10-12 电流反馈增益 0.64–1.20 不一致，是"缺的第二项"的首要嫌疑区）。
4. **气弹簧实际力与摩擦**：核对 400 / 360 N 假设与迟滞；滞回直接改变腿模态阻尼。
5. 若用户批准在实车闭环里注入：0.2 N·m 已知正弦轮力矩，测 5–12 Hz 被控对象响应（10-12 会话明确禁止向实车发激励）。
