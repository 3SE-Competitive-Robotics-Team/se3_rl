## 2. 排除项

- 不是导出问题：两份 ONNX 的 `se3.meta.v2` 只差 export_tag / export_timestamp / policy_iteration，部署契约完全相同，权重不同（sha 8160d29f… / 108a1676…）。
- 不是"静站后起步死锁"：不静站直接给指令，结果逐位相同。
- 不是模拟器差异：800 在 MJLab 与原生 MuJoCo 里一致（1.15/1.80/1.73 对 1.20/1.90/2.41）。
- 不是"靠噪声才动"：MJLab 里 1400 加训练式随机动作并没有更好（1.6 指令下 1.22 对确定性 1.47，卡住 2/6 对 1/6）。

## 3. 成因

**（a）配方阶段性的保守化，训练指标里可见，A15 同一轨迹。** ramp 在 1000 轮结束、台阶 env 从 0 涨到 70%，官方升降级把台阶 env 堆在"刚好过不去"的行（均级 3.7 → 5.0，12 cm）。台阶列账本显示策略在"硬冲（拿跟踪/进度/支撑，吃碰撞/轮离地/倾角罚）"与"慢蹭（少拿也少罚）"之间选了后者：500 → 1400 轮正项少 3.0/s、罚项少 2.9/s，净值持平略升，速度 0.89 → 0.32。原因在奖励结构：进度与支撑按块/按阶一次性发、与速度无关，跟踪核 σ 1.44 与违令罚 scale 3.0 是故意放平的（A10/A11），"再快一点"的边际收益很小，而每秒接触/姿态罚是实打实的。A15 同配方在 1100 轮触底（vx 0.17、进度 0.20），2000 轮后才回到 0.69 / 1.25；M1 在 1600 轮已高于 A15 同期。

**（b）确定性策略长出了"卡住"吸引域，训练指标看不见。** 1400 同时存在"走"与"卡"两个稳定域（1.5 节的常数动作不动点），落进哪个取决于起始状态与扰动：sim2x 的 reset 是默认站姿、0.22 m、零速，每次都落进"卡"域；训练 reset 腿角随机 ±90°、按轮子对齐高度，多数落进"走"域，所以平地列跟踪分保持 0.77。MJLab 里同样的确定性 1400 在 0.8 指令下 3/6 卡住、1.6 下 1/6 卡住，证明这个域在训练分布内也存在，只是被"多数 env 在走"的均值盖住。800 的"卡"域很小（仅 2.4 指令 1/6）。这与 A15 在 4999 轮的高姿起步死锁（`a15_startup_cause_analysis_20260911.md`）是同一现象：台阶列没有零速样本，"从静止进入前进"只在平地列 30% × 10% 的静站样本里练，而这段时间训练分布被"顶在立面前进退不得"的样本占满，"停着"在价值上不吃亏，不动点就在此长出来。

**（c）800 看起来好，是热身平地策略的惯性**：ramp 只走了 2/3、均级 3.7，它反过来站不住（零速漂 0.2–0.27 m/s）、低指令超速、停走停不住。

## 4. 建议

1. 先不改训练，2000 / 3000 轮各拉一次 ONNX，跑本文同一套评测（含确定性台阶通关与 MJLab 逐 env 卡住率）。要看的是 (a) 是否像 A15 一样回来，以及 (b) 的"卡"域是否随之消失；A15 到 4999 轮时低姿能走、高姿仍死锁，所以 (b) 不能指望它自己消失。
2. 若 (b) 不消失，单变量候选（一次只改一项）：高姿起步转移 `high_stand_transition_prob`（A20/A21 验证过对静止起步有效，默认关）；或压 σ / 熵系数，让均值动作而非采样承担前进；台阶进度加速度相关项属于改奖励结构，风险更高，放后。
3. 验收流程：每个 checkpoint 必须跑确定性回放（本文脚本），W&B 曲线只当训练健康度。本例只看曲线会把 1400 判成优于 800。
