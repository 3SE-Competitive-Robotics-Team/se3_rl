# 实车增益 / 高度扫描的仿真预测表（Student128-6998，2026-10-13）

目的：用户即将在实车上对 Student128-6998 做单变量增益与高度扫描。本表给出每组在 sim2x 里的
静站振荡量级、是否站得住、以及一次 8.3 Hz 俯仰角速度观测注入撤除后的衰减（闭环裕度），供逐组对照。
策略固定 `D:/RoboMaster/serialleg2026/build/stm32-policy/Student128-6998/model.onnx`，策略 50 Hz、PD 1 kHz。

- 脚本：`scripts/predict_gain_sweep_20261013.py`；原始数据与汇总：`.scratch/gain_sweep_prediction_20261013/prediction.json`。
- 不改 `src/`、`submodules/`、正式 assets，不连硬件，不做参数拟合。

## 工况配方与增益覆盖方式

- 配方沿用 `.scratch/oscillation_origin_20261012/probe_sim.py`：固件陀螺标量 Kalman 平滑（Q 0.01 / R 0.48，稳态增益 0.134）、腿速度 4.7 ms 一阶滤波（策略观测与 PD 同用）、腿电机 12 ms / 轮 3、4 ms 一阶力矩滞后、气弹簧 400/360 N 在使能后第 6 秒淡入（控制器仍按 300 N 前馈）、回放 2026-10-12 实测静置 IMU 噪声；物理 1 ms、动作延迟 2 ms、腿限矩 ±32 N·m。
- 流程：失能趴姿自然落地 3 s → 使能零速度指令静站 18 s；统计窗 8–18 s（弹簧淡入之后，和 old_measured 一样 10 s）。注入工况另在观测 `base_angular_velocity_body[1]` 上叠加 0.4 rad/s、8.3 Hz 正弦（8–12 s，0.1 s 斜坡），撤除后看物理俯仰角速度的 5–15 Hz 带通 Hilbert 包络。
- 谱估计与实车同口径：Welch，fs 1000，nperseg 900，noverlap 450，5–15 Hz 带内 RMS；谱峰另给 4000 点窗（分辨率 0.25 Hz）。
- 增益覆盖只在诊断 adapter 层：用改过 stiffness / damping 的契约副本重建 `SerialLegActuatorController` 并替换 `adapter._controller`；runtime 契约、观测、动作解码、延迟队列、限矩和弹簧补偿全部不动（每条 JSON 的 `recipe.controller_gains` 与 `recipe.runtime_contract_gains` 分别记录两者）。
- 复现校验：`--stage verify` 用与 probe_sim 完全相同的设置（无噪声、8.144 Hz）重跑，三个窗的谱 RMS 与已保存结果逐数相等（相对差 0.0，见 `probe_sim_replica_check.json`）。顺带发现 probe_sim 的力矩滞后每个 1 ms tick 更新两次（共用 loop 在 `apply_decoded_action` 与 solver step 各调一次 PD），等效时间常数只有 6 ms；本脚本按时间门控改为真正的 12 ms，复现校验用 `legacy_double_lag_update=True` 保留旧写法。

## 结论与实车提醒

- **站得住的组**：主模型下八组都没摔（全程 upright_min_cos ≥ 0.99，启动瞬态除外）。A、B、E、H0.30、H0.38 的 10 s 漂移 ≤ 0.33 m。
- **漂移超过 0.5 m**：C、D（腿 30/2）10 s 内漂移 1.06 / 1.16 m（vx ≈ 0.05 m/s），静态跟踪误差 7–9°（A 的两倍）。实车做这两组请留足场地并随时准备失能。
- **闭环裕度最差的组**：D 在 8.3 Hz 注入撤除后以 8.0 Hz 振铃 1.4 s（时间常数 0.83 s），是所有组里最接近实车 8.1–8.4 Hz 自持振荡条件的一组，尽管它的静站底噪最小。实车若在 D 组看到 8 Hz 振荡增长，应立即退回。
- **振荡最大的组**：E（腿 Kd 6）在主模型下出现 7.5–7.8 Hz 持续振荡并在 18 s 内缓慢增长（俯仰 RMS 逐 2 s 窗 0.07→0.20 rad/s），腿 0.25–0.27°、轮 1.3 rad/s、俯仰 0.18 rad/s，是唯一谱峰落在 7.5–7.8 Hz 的组，也是幅值最接近实车基线的组（实车 0.55–0.64° / 2.8–3.3 / 0.35）。实车预期 E 比 A 振得更厉害，谨慎。
- **对模型版本最敏感的组**：B（轮 Kd 0.1）在主模型下只比 A 略大，但 HEAD 模型下剧烈振荡接近摔倒（腿 3.4°、俯仰 0.83 rad/s、cos 0.85、漂移 6.9 m），工作区模型下 0.33° / 0.65 rad/s / 0.21 rad/s。实车做 B 组要有人盯着。
- **高度**：增益 A 下升高到 0.30 / 0.38 m 后腿角振荡减半到三分之一、跟踪误差缩小，但俯仰角速度 RMS 在 0.38 m 时翻倍（0.019 rad/s），实际站高 0.371 m（差 0.9 cm）；注入都能在 0.3 s 内回到底噪。
- **绝对幅值不能直接对照实车**：主模型下 A 组比实车小 8–30 倍，最差的 E 也小 2–3 倍，仿真仍没有复现 8.1–8.4 Hz 的自持振荡。本表的价值是各组之间的相对排序和"哪组在仿真里就已经不稳"的提示；若实车 A 组的平均站高与漂移更像 HEAD / 工作区模型（站高 +3.5 cm、持续漂移），应改以表 3 的对应列为准。

## 运行

```bash
uv run python scripts/predict_gain_sweep_20261013.py --stage all --workers 8
```

`--stage verify` 只做 probe_sim 复现校验；`--stage recompute` 只用已保存的 npz 重算指标并刷新 `prediction.json` 与 `summary_tables.md`；`--models` 可限定模型版本。51 条工况在 8 进程下约 2 分钟。
