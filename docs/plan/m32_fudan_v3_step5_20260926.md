# M32：M31 + 上台阶列最低一级 5 cm（2026-09-26，用户定）

## 背景

复旦奖励线（M28–M31）上台阶列等级都停在 1.2–1.7。换算成阶高是 4–5 cm，比 6 cm 轮半径矮，其余地形正常升级
（M31 平地、下台阶、坡道在 500 轮就到 6 级左右）。

对照复旦快照：学会上台阶的那几段只有台阶地形，起步等级随机 0–5，阶高 5 cm + 1.8 cm × 等级，最低 5 cm。
我们的上台阶列第 0 级是 2 cm，课程把 env 降到 4–5 cm 就停住。这个高度靠动量滚得过去一半，
策略很少遇到必须动腿的台阶。

本 run 检验"去掉 2–4 cm 这段退路"是否足以逼出动腿上台阶。

## 改动（相对 M31 唯一差异）

任务入口 `SE3-WheelLegged-Rough-Exp-FudanRewardOri10Std15NoWarmupStep5`：`env_cfg(...,
stairs_up_step_height_range=(0.05, 0.20))`，只改上台阶列的阶高范围，下台阶列与二级台阶列不变。

- 等级 → 阶高：5.0 / 6.7 / 8.3 / 10.0 / 11.7 / 13.3 / 15.0 / 16.7 / 18.3 / 20.0 cm（M31 是 2 + 2 × 等级 cm）。
- 地形感知高度下限（阶高 + 0.14 m，夹在 0.20–0.38）按新阶高自动计算，2 级起比 M31 同级略高。
- 等级数字与 M28–M31 不再同尺度：比较时换算成阶高，M31 的 1.3 级 ≈ 4.6 cm，对应本 run 的 0 级以下。
- `scripts/eval_stair_climb.py` 的等级映射仍是旧的 2 cm 起步，评测时按阶高对照。

奖励（复旦 v3 + orientation −10 + 格点高度参考）、init_std 1.5、无平地热身、指令、终止、观测、域随机化都与 M31 相同。
