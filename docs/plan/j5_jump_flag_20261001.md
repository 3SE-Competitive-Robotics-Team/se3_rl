# J5：jump_flag 窗口触发、按状态给奖励的跳跃策略（2026-10-01，用户定）

## 动机

J1–J4 是按时间模仿参考：actor 需要 20 维参考帧才知道"现在在这一跳的哪里"，契约是 54 维，接进 rough 要改网络输入层。
复旦 jump 工程（yly-true/fudan_rl_wheel_leg）不用参考也不用相位：跳跃奖励全按状态触发（离地、上升速度、蹬地伸腿、
空中收腿、腾空高度），策略本身会连续蹦；其 sim2sim（`mujoco/python_tools/onnx_mj_chuanlian.py`）按空格切入跳跃
策略、0.55 s 后切回上台阶策略，"跳一次"靠这个时间窗实现，落地交给行走策略。

J5 把这个时间窗搬进训练、放进同一个策略：jump_flag 置 1 保持 0.5 s 再置 0。窗口内该做的事都能由当前状态判断
（站着 → 蹬，离地 → 收腿），不需要相位。契约与 rough 一致（34 维，跳跃槽位 flag / 目标高度 / 相位恒 0），
验证通过后可从 M54 热启动合进 rough。

## 任务 `SE3-WheelLegged-Jump-Flag-MLP`（`src/se3_train/tasks/jump_flag/`）

以 Flat-MLP 为底，执行链与 J4 / M54 相同（腿部 T-N 包络 ×0.8、300 N 气弹簧前馈补偿），从头训，平地。

- **指令**：vx ±2.4（保留 20% 零速，无速度课程），yaw / pitch / roll 恒 0，站姿高度 0.20–0.24（用户定：低站姿留足
  蹬地行程，到起跳高度约 0.374 m 还有 0.13–0.17 m，直接蹬即可到 0.40–0.50 m，不规定下蹲，必要时策略自己快速下沉）。
- **触发**：站满 1 s 后每秒 0.5 概率触发；jump_flag = 1 保持 0.5 s，jump_target_height 在窗口内给出目标轮底离地间隙
  （0.20–0.50 连续），jump_phase 恒 0。
- **跳跃事件**：触发 → 离地后再触地并稳住 0.5 s（或窗口结束仍未离地，或超过 2.5 s）。事件期间冻结速度 / 高度指令；
  只认第一次离地，落地后再离地算二次起跳。
- **跳跃奖励**（只在第一次落地前有效，按秒计）：上升速度 max(vz, 0) ×3.0、两轮离地 ×2.0、空中收腿（虚拟腿长 → 0.16）×1.0；
  触地那一步一次性给最高点奖励 10·exp(−(最高轮底间隙 − 目标)² / 0.08²)；窗口结束仍未离地一次性罚 −10；
  事件内落地后再离地 ×−4。
- **事件屏蔽**：事件期间置零轮子离地罚、机身高度罚、静站罚、接触力罚，速度跟踪核去掉 vz 项。Flat 这些项自身只按
  jump_flag 屏蔽，而 flag 在窗口结束时往往还在空中，所以按事件再屏蔽一层。
- **观测**：actor 34 维（与 rough 契约同布局）；critic 95 维，另含事件状态（事件中、进度、窗口内、已离地、已落地、
  落地后进度、目标间隙、当前轮底间隙）。
- **reset**：Flat 根状态（默认站高 0.22）+ 关节 ±0.1 rad 扰动，不用 Flat 的 ±90° 髋随机化。回合 10 s，PPO 同 Flat-MLP。

## 观察点

- `Jump/missed`（漏跳）是否降到接近 0；`Jump/apex_clearance` 与 `Jump/apex_error_abs` 是否随目标收敛。
- 二次起跳（`jump_rehop`）、落地摔倒是否可控。
- 回放：不同 vx 与目标高度下按一次跳一次；对照 J4 的离地精度与落地稳定性。

## 部署

ONNX 契约：jump_flag (0, 1)、jump_target_height (0, 0.5)、jump_phase (0, 0)、vx ±2.4、高度 0.20–0.24；没有 `jump_reference`。
sim2x 的 Jump / T 现在只驱动 J 系列的参考播放器，回放 J5 需要 runtime 增加"flag 脉冲"（按下后 jump_flag = 1、
目标高度 = 所选值，保持 0.5 s；窗口长度应写进 metadata，不在 runtime 写死），待训练出结果后再做。

  事件中 vx 指令冻结；全程奖励与观测有限。
