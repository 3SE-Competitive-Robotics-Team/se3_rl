## 指令与奖励的分列归属

用户要求新列 ±2.4 且下台阶有偏航跟踪，等于让它们**按平地方式发指令**：

| | 走哪条路 | 速度 | 偏航 | 静站/高姿转移 |
|---|---|---|---|---|
| flat、stairs_down、slope_up、slope_down | 平地（`ROUGH_TERRAIN_COMMAND_FLAT_NAMES`） | 跟平地课程，终值 ±2.4 | 平地范围（课程终值 ±12 rad/s） | 参与 |
| stairs_up | 非平地覆盖 + 台阶覆盖 | 1.0–2.4 前向 | 恒 0 | 不参与 |

奖励侧：

| 项 | 生效列 |
|---|---|
| 台阶专项（`stair_climb_progress` / `stair_support_height`） | 只 stairs_up |
| 三项接触税置零（`ROUGH_CONTACT_TAX_FREE_COLUMNS`） | stairs_up + **stairs_down**（上下台阶都会抬轮跨立面） |
| 偏航跟踪置零、放宽运动核 1.44 | 只 stairs_up（下台阶保留偏航跟踪，按用户要求） |
| 机身高度罚 | 全列（M3 起） |
| 速度违令罚 | 全列（`ROUGH_ALL_TERRAIN_TYPE_NAMES` 随比例字典自动扩） |
| 地形感知高度下限 | 只 stairs_up（下行台阶在身后，抬高只升重心） |

## 待确认

平地课程的偏航终值是 ±12 rad/s（约 687°/s）。新列跟平地走就会吃到这个上限，
坡面与台阶上高速转向的风险没验证过。若要限，给新列单独一档偏航范围即可。
