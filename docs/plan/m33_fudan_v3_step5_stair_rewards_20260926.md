## 背景

复旦奖励线的五条 run 都没练出动腿上台阶：

| run | 改动 |
|---|---|
| M28 | 姿态罚 −20 |
| M29 | 姿态罚 −10 + 复旦格点高度 |
| M30 | 初始 std 1.5 |
| M31 | 去掉平地热身 |
| M32 | 上台阶最低一级 5 cm |

M28–M31 的上台阶等级停在 4–5 cm；M32 连第 0 级（5 cm）都没过。其余地形都正常，平地、下台阶、坡道 400–500 轮就到 6 级。

复旦奖励表里没有任何项奖励"爬上台阶"本身；本仓库的奖励表（M25–M27）有两项台阶专项奖励，同样从零训练，
上台阶能到 4–6 级。本 run 检验"缺的是爬台阶的激励"。

## 改动（相对 M32 唯一差异）

任务入口 `SE3-WheelLegged-Rough-Exp-FudanRewardStep5StairRew`：`env_cfg(..., fudan_stair_rewards=True)`，
在复旦 15 项之外原样加回：

| 项 | 权重 | 计酬方式 |
|---|---|---|
| `stair_climb_progress` | 3.0 | 平台外新增的最大切比雪夫进度（m/s），后退再走回不重复计；直立门控 |
| `stair_support_height` | 4.0 | 双轮持续支撑在更高一级踏面 0.1 s 后，每阶每 episode 计一次 |

两项只在上台阶列（与二级台阶上行列）生效，权重与参数与本仓库默认奖励表相同，不套复旦的每秒 ±1 限幅（支撑奖励是
一次性脉冲，限幅会把它削掉）。整段爬完 4 级约 3 × 2.8 m + 4 × 4 = 24.4，复旦 15 项的正项上限约每秒 3（20 s 共 60）。

其余与 M32 相同：复旦 v3 + orientation −10 + 格点高度参考、init_std 1.5、无平地热身、上台阶列阶高 5–20 cm。
