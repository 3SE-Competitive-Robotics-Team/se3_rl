# Rough 高姿态起步序列占比 0.5 → 0.1（HighStand01，2026-10-04）

## 改动

`high_stand_transition_prob`（平地列每次重采样生成"0.36–0.38 m 高姿态静站 1.5–2.5 s → 以 0.8–2.4 m/s 前进"序列的概率）
0.5 → 0.1，其余与当时默认（姿态罚 −24）相同。0.5 时任意时刻约 26% env 处在该序列中（waiting 11% + moving 15%），0.1 时 5.4%。

依据：中等高度（0.26–0.34 m）0.5–1.5 m/s 稳态机身比指令高 4–6 cm；反事实账本显示贴合指令高度时策略自己的奖励反而更高
（没学好，不是奖励权衡），嫌疑是高姿态序列挤占了"中等高度 + 前进"的数据（docs/plan/rough_orient24_20261004.md）。
风险：该序列是 M8 为解 0.38 m 静站起步的探索瓶颈加的。

高姿态起步变慢、跳跃略矮。2026-10-04 用户定为新默认（`env_cfg.ROUGH_HIGH_STAND_TRANSITION_PROB = 0.1`）。单 seed。
