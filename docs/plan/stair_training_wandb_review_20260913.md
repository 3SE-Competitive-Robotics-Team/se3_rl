# Rough 台阶训练 W&B 对照实验总览（2026-09-13）

目的：在收束整理 rough 任务代码之前，把 W&B 上全部台阶训练对照实验的变量、结果和结论摆到一张表上，明确哪些机制被数据支持、哪些被否定、哪些没有分辨力，作为决定"默认配置保留什么、实验入口删掉什么"的依据。

## 核实范围与口径

- 数据源：W&B 项目 `luzhongjin365-se3/SE3-WheelLegged-Rough` 全部 58 个 run（2026-09-06 R1 至 2026-09-13 A28-cap3），本机通过 `wandb.Api` 直接读取 config 快照与 history。缓存：`.scratch/rough_wandb_runs_20260913.json`（清单）、`rough_wandb_tail50_20260913.json`（尾窗统计）、`rough_wandb_config_matrix_20260913.json`（配置矩阵）；脚本 `.scratch/rough_wandb_list_runs.py`、`rough_wandb_tail_metrics.py`、`rough_wandb_config_matrix.py`。
- 统计窗口：每个 run 取最后已同步的 50 轮，对每个数值键求有限值均值。finished 的 run 是 4950–4999 或 950–999；crashed 的 run 是崩溃/停止前最后 50 轮。W&B 的 crashed 多为网关断连或用户手动停止，不代表数值崩溃（见 `.agent-handoff/snapshot.md` 各条）。
- 全部 run 都是 seed 42、24 步/env；env 数为 1×/3×/4×/6× 8192 不等，见表内。**没有任何一组是多 seed 对照**。
- 指标口径：`terrain_levels/stairs_up` 只升不降，是课程推进历史，不是当前成功率；`stair_supported_steps` 是当前 candidate 的分组均值（踩住几级踏面）；`base_vx_terrain`、`cmd_vx_terrain`、`tracking_lin_vel_flat` 在几乎所有 run 里都有 NaN 轮（表中带 `*`），均值只取有限轮，不是无偏估计；`terrain_cleared` 是每轮清块终止次数，随 env 数和 episode 长度缩放，只能同 env 数内比。
- sim2x 实测结论引用自 `.scratch/a2x_*_report.md`、`.agent-handoff/snapshot.md` 与 `docs/plan/a15_startup_evaluation_20260911.md`，均为固定指令下的单条确定性路径，不是统计成功率。

## 2. 被数据支持的结论

1. **台阶专项奖励组是必要条件**：进度奖励、支撑奖励、台阶列高度罚置零、台阶列速度违令罚四项缺一则台阶列速度归零（A12 消融 A3/A5/A7/A8；RewardAbl 四组；A16、A17 两次整列替换/抹平也归零）。
3. **A15 的非台阶列定价是目前最好的从零配置**，且是后续全部 warm-start 的公共起点；A13b 的 1×/4× 差异提醒这一优势没有经过多 seed 检验。
4. **高姿起步转移指令（A20/A21）有明确正效果**（sim2x 0.38 m 静站起步 0.05→0.8–2.1 m/s），代价是灾难终止升高、越界后失稳。
5. **100% 台阶训练与整套换奖励都退化**（A16、A27×2、A28×2）：训练分布里不能没有平地列，奖励结构不能整列替换。
6. **没有分辨力或不充分**：A22 零速门控（vs A23）、A19 高度门控（vs A18）、A6 能耗定价、A25 弱高度罚、A28-cap3 课程封顶。
7. **未在 W&B 上跑过**：A14 reset 帧 last_actions 随机化（`reset_last_action_range`）没有对应 run。

## 4. 对收束的建议（待用户决定，不是已执行项）

2. 高姿起步转移（`high_stand_transition_prob`）和台阶零速指令（`stair_lin_vel_x_range` 含 0）是两个"有理由开、有代价"的旋钮：前者 sim2x 起步实测有效但灾难终止升高；后者训练内无分辨力但停走验收需要它。建议保留参数，默认值按验收表定，不要静默改。
3. 上一条之外的实验专用参数（第 3 节列表）若删，一并删对应测试分支；若留，在 `env_cfg` 注释里标明"仅历史实验使用、无正结论"。
4. 无论默认值怎么定，写进 `tests/test_rough_port.py` 逐项守护（照 Flat 基线 `test_flat_baseline.py` 的做法），改默认值必须同步改测试并在提交信息里写对照实验编号。
5. 下一轮如需再做训练对照，优先补 A15 配置的第二个 seed，再谈其他变量；A13b 的 1×/4× 差异说明现有全部结论都建立在单 seed 上。
