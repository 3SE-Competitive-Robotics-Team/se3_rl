`/srv` 是约 49 GB 的持久化块存储，放仓库、虚拟环境与小文件缓存；
`/root/highspeedstorage/am345` 是约 10 TB 的 JuiceFS，放 logs、checkpoints 与 W&B。
`/root/dataDisk` 容量仅约 10 GB，不用于本项目。

远端直连 `files.pythonhosted.org` 很慢。初次同步依赖时，可临时使用只替换下载域名、
不改变版本与哈希的 `/srv/se3-config/uv.aliyun.lock`；同步结束必须恢复仓库原始
`uv.lock`。需要访问 GitHub 或其他外网时，先在本机执行：

```powershell
boring open gpufree-162-proxy
```

然后在远端按需执行：

```bash
source /srv/se3-config/se3-proxy-env.sh
```

训练默认不依赖本机隧道，W&B 无稳定外网时使用 offline 模式。
